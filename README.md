# LAN Remote Control

Веб-сервер для удаленного управления компьютером на Windows 10/11 с телефона, планшета или другого ПК через браузер. 

Основная цель проекта — получить минимальную задержку при трансляции экрана и звука по локальной сети (или через VPN вроде Radmin / Tailscale), без необходимости ставить тяжелый сторонний софт на телефон. Работает как PWA (Progressive Web App).

---

## Что внутри

### 1. Захват экрана и звук в 60 FPS
* **Direct3D 11 / Windows.Graphics.Capture API** — чтение кадра напрямую из видеопамяти (как в OBS), что дает задержку захвата около 0 мс и не грузит процессор. Для старых сборок или нестандартных сценариев есть fallback на MSS.
* **SIMD AVX2 JPEG (`simplejpeg`)** — сжатие каждого кадра за 2–4 мс.
* **Ограничение разрешения (1080p Lock)** — для 2K и 4K мониторов поток пережимается до Full HD, чтобы не забивать Wi-Fi канал и стабильно держать 60 кадров.
* **WASAPI Audio Loopback** — перехват всего системного звука Windows (игры, видео, браузер) в 48 кГц Stereo 16-bit PCM и отправка по WebSocket прямо в Web Audio API браузера.
* **Кнопка паузы** — мгновенно останавливает захват и освобождает 100% ресурсов GPU/CPU, когда трансляция не нужна.

### 2. Управление
* **Виртуальный трекпад / мышь** — мультитач, прокрутка двумя пальцами, зажатие левой кнопки (Drag) для перетаскивания окон и правый клик.
* **Сенсорный геймпад** — D-Pad, кнопки A/B/X/Y, бамперы и триггеры с виброоткликом. Автоматически подстраивается под портретный и повернутый (90°) режимы экрана.
* **Touch Deck (макросы)** — сетка быстрых кнопок: громкость, переключение треков, открытие программ, запуск скриптов, горячие клавиши. 43 встроенные SVG-иконки.
* **Виртуальная клавиатура** — быстрый ввод текста и системных сочетаний.

### 3. Системные утилиты
* **Диспетчер задач** — список запущенных процессов с сортировкой по CPU/RAM, завершение процессов, изменение приоритета и запуск новых задач.
* **Мониторинг GPU** — нагрузка по ядрам 3D, Video Decode, Video Encode, занятая видеопамять и температура.
* **Файловый менеджер** — навигация по дискам (`C:\`, `D:\` и т.д.), скачивание и загрузка файлов.
* **Буфер обмена** — история последних 5 скопированных текстов с возможностью вставки в один тап.
* **Уведомления** — отправка Windows Toast уведомлений с телефона на ПК.

## Как запустить

### Способ 1. Готовый EXE-файл (без Python)
1. Скачайте `LAN-Remote.exe` со страницы [Releases](https://github.com/yksyse/lan-remote/releases).
2. Запустите файл. Сервер автоматически найдет свободный порт (по умолчанию `8080` или `8090`, если 8080 занят) и выведет локальный IP в консоль.
3. Откройте этот IP на телефоне в браузере.

### Способ 2. Запуск из исходников

Требуется Python 3.10+ на Windows 10 или 11.

```bash
git clone https://github.com/yksyse/lan-remote.git
cd lan-remote

pip install -r requirements.txt
python server.py
```

По умолчанию сервер слушает порт `8080`. Можно передать другой порт через аргумент:
```bash
python server.py --port 8090
```

## Как пользоваться на телефоне (PWA)

1. Убедитесь, что телефон и компьютер находятся в одной локальной сети (Wi-Fi) или в одном VPN (Radmin, ZeroTier, Tailscale).
2. В браузере (Chrome / Safari / Firefox) откройте `http://<IP_вашего_ПК>:8080`.
3. В меню браузера нажмите **«Добавить на главный экран»** (Add to Home Screen) — интерфейс откроется в полноэкранном режиме без адресной строки.
4. Нажмите иконку звука на верхней панели трансляции, чтобы запустить аудиопоток (браузеры требуют первого нажатия для разблокировки аудио).

## Сборка автономного бинарника

Если вы внесли изменения в код и хотите собрать свой `.exe`:

```bash
pip install pyinstaller
pyinstaller --noconfirm LAN-Remote.spec
```

Готовый файл будет лежать в `dist/LAN-Remote.exe`.

## Структура проекта

```text
lan-remote/
├── core/
│   ├── screen_streamer.py   # Direct3D 11 и MSS захват экрана (60 FPS)
│   ├── audio_streamer.py    # WASAPI Loopback захват системного звука
│   ├── input_driver.py      # Эмуляция мыши, трекпада и клавиатуры
│   ├── system_manager.py    # Метрики CPU, GPU, буфер обмена, батарея
│   ├── task_manager.py      # Диспетчер задач и управление процессами
│   ├── file_manager.py      # Файловый менеджер дисков
│   └── config_manager.py    # Хранение и загрузка настроек
├── static/
│   ├── index.html           # Интерфейс управления
│   ├── css/style.css        # Стили и темы оформления (OLED, Cyberpunk, Slate, Glass)
│   ├── js/                  # Логика клиента (стрим, звук, дек, диспетчер)
│   └── icons/               # Векторные SVG-иконки
├── server.py                # FastAPI сервер и WebSocket роуты
├── requirements.txt         # Зависимости
├── LAN-Remote.spec          # Спецификация для PyInstaller
└── LICENSE                  # MIT License
```
